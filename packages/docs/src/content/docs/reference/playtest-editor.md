---
title: Playtest editor
description: Reference for starting playtests, sharing invite links, and collecting feedback.
---

The playtest editor publishes a playable copy of a game and manages feedback from players.

## Opens from

Open a game, then choose **Playtests**.

## Starting a playtest

Use **Start playtest** to export the current project files and create a private playtest room. The playtest is registered with the local project so feedback can be imported later.

## Invite links

Each playtest shows an invite URL.

- **Copy** copies the invite link.
- **Open** opens the playtest directly.

Players can join from the invite page by signing in or continuing as an anonymous user.

## Player experience

When a player opens a playtest, Digitable imports the playtest project into browser storage and connects to the private playtest room. Players interact with the game through the play surface.

## Feedback

Playtests include a notes panel for private feedback. Players can write formatted notes and submit them to the playtest.

The playtest editor lists submitted feedback for each playtest, including the note title, author, submission time, and note body.

## Importing feedback

When the playtests page loads, Digitable checks registered playtests and imports available feedback into the local project.
