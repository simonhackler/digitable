title: Getting started
description: A guide to quickly create and playtest a boardgame
---

To get started with digitable simply click this link here: https://digitable.ink/app/games

Digitable is a board game engine. It allows you to design, playtest and publish your games.
The focus is on allowing quick iterations with playtesting and designing, while allowing you to use the same project for
creating professional print files.
Digitable is based on files. This means almost everything in digitable is a file and will be saved on your device.
This allows you to edit digitable with whatever programs you like.
So you can use the inbuilt editors or you can use inkscape to edit components and excel to edit the spreadsheets.

In Digitable you can either store your files in the browser or on your system.
I recommend using files on your system.

:::note
If you want to store your files on your computer, use a Chromium-based browser
such as Chrome, Edge, Opera, or Brave.

Firefox does not support accessing local files in the way Digitable requires.
:::

:::caution
Digitable currently does not sync your game files automatically.

Make sure to back up your project files yourself. File syncing may be added
later as a paid option.
:::

After choosing a folder, create a new game. Give your game a name, select the
number of players, and optionally add a description.

Now create a component in the deck dropdown on the left and open it.

## Svg editor

In the editor view you can create a custom card. For now, just create a full width rectangle in whatever color you like.
Now add a textbox in the middle of the screen to it. The text inside can be "whatever". Next click the button in the top left to navigate to the
spreadsheet view.

## Spreadsheet

In digitable you have components, like the one you just created. You then use a spreadsheet to generate different versions of that component.
Let's try it out. Add a new row to the spreadsheet and change the text to "something else".
As you can see you now have 2 different cards based on your template.
You can now export the game to paper or Tabletop Simulator to playtest it. Or even better you can setup a playtest directly in digitable.
For that navigate to the setup page.

## Setup

On the setup page, you setup (duh) the game view. For now the default table is too large so let's resize it to something smaller like
500x500 by clicking on resizetable. Next click add component and add the one deck you created before.
That is it for setup. You can now test it out by clicking on Local Test. Then it is time to create a Playtest.

## Playtest

Now you can create a new playtesting session, invite your friends and start the sessions. Your players can then immediately leave feedback
inside the playtesting session.

## Publish

When you are happy with the current state of your game you can publish it. Either as an early access version or release.
You can always update the files later.
